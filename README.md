
# BRASS-HELL-BULLET-AHK
autohotkey 2.0 script for brass hell bullet on roblox / bullet making automation only.

How to setup press f7 on the top left of the E:(Example) text [IT HAS TO BE REALY CLOSE TO THE TOP LEFT OF THE E:] and the bottom right this box has to be big so the program can read the text properly.



Dissable workbench helpers it you have them

After you setup the box press f6 while on the work bench to toggle on and off the program.

The program will stop when it reads that you need to restock your supplies


PS. This program was made entirely by ai.
